# Technology logos

Used only in the course badges (`src/data/tech-logos.ts`) to identify the technology a course teaches
(nominative use), unaltered apart from size. Each name and logo is a trademark of its owner; DataDank is not
affiliated with or endorsed by any of them.

| File | Owner and guidelines | Source of the SVG |
|---|---|---|
| `python.svg` | Python Software Foundation, <https://www.python.org/psf/trademarks/> | devicon 2.17.0 `python-original` |
| `spark.svg` | Apache Software Foundation (Apache Spark), <https://www.apache.org/foundation/marks/> | devicon 2.17.0 `apachespark-original` |
| `kafka.svg` | Apache Software Foundation (Apache Kafka), <https://www.apache.org/foundation/marks/> | devicon 2.17.0 `apachekafka-original`, fill set to the official #231F20 |
| `airflow.svg` | Apache Software Foundation (Apache Airflow), <https://www.apache.org/foundation/marks/> | devicon 2.17.0 `apacheairflow-original` |
| `snowflake.svg` | Snowflake Inc., <https://www.snowflake.com/brand-guidelines/> | Simple Icons 16.35.0, brand colour #29B5E8 |
| `databricks.svg` | Databricks, Inc., <https://brand.databricks.com/> | Simple Icons 16.35.0, brand colour #FF3621 |

Not used, so those courses keep text badges: dbt (no logo in either library; dbt Labs' mark was withdrawn from
Simple Icons), Delta Lake (no source logo found), AWS (Amazon's trademark guidelines restrict third-party use
of the AWS logo), and PySpark (no separate official logo; the Spark logo would make two cards identical).

Kafka's logo is single-colour black; on dark themes it is shown inverted (white), the standard reverse version.
